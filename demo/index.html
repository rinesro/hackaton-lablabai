Each page below was generated by the onboarding-assistant skill running inside IBM Bob IDE: four parallel subagents analyzed the repository, wrote the docs, and a zero-dependency script turned them into one static site.

The analysis itself runs inside Bob IDE, so these pages show the output of the tool. To generate one for your own repo, open it in Bob, switch to the Onboarding Guide mode, and run /onboarding-assistant.
