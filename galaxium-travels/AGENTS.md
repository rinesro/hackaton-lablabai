## What is this repo?

**Galaxium Travels** is a fictional luxury interplanetary space-travel booking
system used as IBM Bob's primary tutorial/demo application. It is a full-stack
app with a React + TypeScript frontend and a FastAPI + Python backend backed by
SQLite.

## Running the app locally

### Quick start (recommended)
```bash
# macOS / Linux
./start.sh

# Windows
start.bat
```

### Manual start
```bash
# Backend
cd booking_system_backend
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python server.py             # → http://localhost:8080

# Frontend (new terminal)
cd booking_system_frontend
npm install
npm run dev                  # → http://localhost:5173
```

### Service URLs
| Service              | URL                          |
|----------------------|------------------------------|
| Frontend dev server  | http://localhost:5173        |
| Backend REST API     | http://localhost:8080        |
| OpenAPI / Swagger UI | http://localhost:8080/docs   |
| MCP endpoint         | http://localhost:8080/mcp    |

## Agent guidelines

- **Backend changes** — edit files inside `booking_system_backend/`. Run
  `pytest` from that directory to validate.
- **Frontend changes** — edit files inside `booking_system_frontend/src/`.
  Run `npm run build` inside `booking_system_frontend/` to type-check and build.
- **Do not** modify `dist/` directly; it is a build artifact.
- **Environment** — the frontend reads `VITE_API_URL` from
  `booking_system_frontend/.env`. Default is `http://localhost:8080`.
- **Branch** — this workspace is on `bob-learning-path-branch`; open PRs
  against that branch.
